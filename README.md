# Смоленский транспорт — прототип сайта

Статический сайт-лента из постов группы ВКонтакте «Смоленский транспорт»: https://vk.ru/smolensk_transport

- `index.html` и `media/` публикуются через GitHub Pages.
- `src/` — генератор: `posts.json` (тексты постов, как они вышли на стене), `template.html`, `gen.py`.
